# 视觉叙事与画面判断

统一代码视频、视频审美和实际成片经验；按当前题目的解释或故事目标选择，不要求固定五幕、效果次数、材质数量或角色出场比例。

## 先写行动与后果

镜头表写清实体与稳定 id、条件、动作、关系变化和可观察后果。一个物体的移动、一个候选的退出、一次选择改变剩余集合，都比抽象词配标题卡更容易追踪。纯粹的比较和必要的凝视可以保持静止；有意义的静止不算缺少动作。

| 内容 | 合适的画面动作 | 必须留住的信息 |
| --- | --- | --- |
| 机制、推导 | 同一对象移动、组合、拆解、连接或重新归类 | 对象身份、条件、每步变化 |
| 证据、争议 | 定位原材料、高亮、并列核对 | 原上下文、出处、主张边界 |
| 数量、分布 | 建立单位和坐标，逐步加入数据、比较与标注 | 分母、单位、比例；非比例示意需声明 |
| 故事、选择 | 行动、可见后果、反应与必要停顿 | 行动选项、约束；情节不能当实证 |

故事需要贯穿物时，选可画、可调度的具体物件。角色或视觉原子跨镜复用以形成呼应，复用次数由叙事决定。前后同机位比较可以展示改变，但不能替代条件或因果说明。

## 关键帧与身份

先画最能解释问题的一帧和变化终态，再检查中途。主图优先；标签、色彩、路径让同一实体可追踪。换位置、尺度或场景时给空间线索，避免观众把移动认成换了对象。颜色辅助区分，关键身份不能只靠颜色。

定义本片实体到形状、标签和语义色的映射。保持实际对象身份稳定，不要求每期用同一配色、纸纹、卡片或正反两栏。字体按实际加载的字形测量、折行和排版，不能靠字数估宽保证不越界。

主图、图注、字幕分区；字幕保留限定，不能独自完成全部机制。按本片宽高、观看尺寸、实际行数确定安全区。竖屏字幕坐标和字号不能照搬横屏；手机查看可读性，不把整张宽图机械缩小。

## 材质与效果

效果应强调当前动作、转折或介质。纸纹、扫描线、色差、颗粒或发光有各自适用的画面；叠加之前确认它是否服务内容，并看实际成片中的主体、文字与层级。

强调转折的效果可以短促，持续表现介质的效果可以常驻。没有固定的效果次数、时长或强度门槛。检查效果前、峰值、结束后；相机抖动、缩放和转场不能裁掉必读的文字或暴露画布边缘。效果参数以当前实现与实际帧为准，不把旧插件的某个数值变成通用规则。

PSNR、亮度差或像素运动可以定位状态变化与穿帮，不能证明某个版本更美、更有情绪或解释更好。需要颜色、数量或位置不变时检查真实主体内部和边界；中心采样正确不能排除横线或高亮覆盖。无损源帧的精确证据与有损 MP4 的近似像素分开表述。

## 声音、事件与停留

已有歌曲或录音优先复用。音乐驱动的镜头按实际 BPM 与拍偏移安排；旁白驱动的动作按已取得的时间依据安排。说到“排除”时候选退出，说到“汇合”时路径合并；对象尚未被建立时，画面不提前揭示结论。

provider 句/词 boundary、对已有音频的对齐结果、实际分段长度是不同依据。保存来源、文本和整片偏移；provider WordBoundary 不等同于声学强制对齐。没有词级依据时使用真实段级边界，或把细分时点明确标为编辑估计，避免伪装成逐词同步。

最后一个动作或信息落定后才计算阅读和比较停留。镜头长度依据观察、推理、情绪及用户目标，不强制长短比例。旁白与音乐共存时核对可懂度和混音；SFX、连续音乐床、主题旋律回归都按需要使用，不要求每片加入。

## 看实际结果

暂时遮掉字幕，主要对象和动作仍应可追踪。图面是否表达关系、故事是否有行动后果、限定是否足以改变判断，都用具体时码检查。先改解释动作或构图，再加装饰。

反复出现的缺陷落实成代码能力：字体测量、折行、布局边界、事件 cue、任意时间重画、缓存失效、关键帧检查。不依靠继续堆“精致、有趣、高级”的提示词。
