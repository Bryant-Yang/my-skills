# 视觉叙事与画面判断

统一代码视频、视频审美和实际成片经验；按当前题目的解释或故事目标选择，不要求固定五幕、效果次数、材质数量或角色出场比例。

## 先写行动与后果

镜头表写清实体与稳定 id、条件、动作、关系变化和可观察后果。一个物体的移动、一个候选的退出、一次选择改变剩余集合，都比抽象词配标题卡更容易追踪。纯粹的比较和必要的凝视可以保持静止；有意义的静止不算缺少动作。

若视频基于外部热帖、论文或公开演讲改编，动笔前先区分使用场景：内部复盘与学术引用可保留原案例并在画面显式署名；面向公域平台的原创视频则应从立项起换用自有实验、独立算例或一手测得素材，不沿用原帖标志性的段子与翻车梗，避免成片后因核心案例撞车而返工。

| 内容 | 合适的画面动作 | 必须留住的信息 |
| --- | --- | --- |
| 机制、推导 | 同一对象移动、组合、拆解、连接或重新归类 | 对象身份、条件、每步变化 |
| 证据、争议 | 定位原材料、高亮、并列核对 | 原上下文、出处、主张边界 |
| 数量、分布 | 建立单位和坐标，逐步加入数据、比较与标注 | 分母、单位、比例；非比例示意需声明 |
| 故事、选择 | 行动、可见后果、反应与必要停顿 | 行动选项、约束；情节不能当实证 |

故事需要贯穿物时，选可画、可调度的具体物件。角色或视觉原子跨镜复用以形成呼应，复用次数由叙事决定。前后同机位比较可以展示改变，但不能替代条件或因果说明。

## 关键帧、首帧与过渡中途

关键帧审阅不能只抽每幕接近结束的静止终态，至少覆盖三类时刻：

1. **`t = 0` 封面首帧**：多数播放器默认抓取第 0 帧作缩略图，首帧应呈现完整可读的主结构或对比底图，再随旁白推进高亮与增量动画，避免入场前留下空洞面板。
2. **动态变形中途帧（如 `p ≈ 0.3–0.5`）**：凡包含宽度生长条块、滑入卡片或路径推进的场景，必须抽查未长满时的中途帧，确认条内文字已做裁切遮罩、相邻标签与圆点指示器未压字越界。
3. **关键变化终态**：检查最终数值、结论徽章、外部嵌入截图的真实宽高比（防非等比拉伸把圆形压成椭圆）及底部图注与字幕区的垂直间距。

定义本片实体到形状、标签和语义色的映射。颜色辅助区分，关键身份不能只靠颜色。字体按实际加载的字形测量、折行和排版（如 `ctx.measureText`），不能靠字数估宽保证不越界。主图、底部要点条、字幕与出处栏分层布局，字幕区独立留白，不压住图面数据。

## 材质与效果

效果应强调当前动作、转折或介质。纸纹、扫描线、色差、颗粒或发光有各自适用的画面；叠加之前确认它是否服务内容，并看实际成片中的主体、文字与层级。

强调转折的效果可以短促，持续表现介质的效果可以常驻。没有固定的效果次数、时长或强度门槛。检查效果前、峰值、结束后；相机抖动、缩放和转场不能裁掉必读的文字或暴露画布边缘。

PSNR、亮度差或像素运动可以定位状态变化与穿帮，不能证明某个版本更美、更有情绪或解释更好。需要颜色、数量或位置不变时检查真实主体内部和边界；中心采样正确不能排除横线或高亮覆盖。无损源帧的精确证据与有损 MP4 的近似像素分开表述。

## 声音、事件与停留

已有歌曲或录音优先复用。音乐驱动的镜头按实际 BPM 与拍偏移安排；旁白驱动的动作按已取得的时间依据安排。说到“排除”时候选退出，说到“汇合”时路径合并；对象尚未被建立时，画面不提前揭示结论。

当一幕解释包含两三句递进判断时，让画面在同一空间结构上分阶段点亮，同时让屏幕字幕随每句真实音频边界切换短句，避免挂一条跨十几秒的超长双行字幕。provider 句/词 boundary、对已有音频的对齐结果、实际分段长度是不同依据；没有词级依据时使用真实句段边界，或把细分时点明确标为编辑估计。

最后一个动作或信息落定后才计算阅读和比较停留。旁白与音乐共存时核对可懂度和混音；SFX、连续音乐床、主题旋律回归都按需要使用，不要求每片加入。

## 看实际结果

暂时遮掉字幕，主要对象和动作仍应可追踪。图面是否表达关系、故事是否有行动后果、限定是否足以改变判断，都用具体时码检查。先改解释动作或构图，再加装饰。

反复出现的缺陷落实成代码能力：实测字宽断言、生长容器遮罩、等比贴图、句级事件 cue、任意时间纯函数重画、区间缓存失效与中途帧抽检，不依靠堆砌抽象形容词。
