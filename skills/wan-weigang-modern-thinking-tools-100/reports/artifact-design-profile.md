# 输出呈现规范

本 Skill 的默认产物是高信任度的决策备忘，而不是课程讲义、概念百科或视觉仪表盘。

- 首屏先出现结论，不以理论背景开场。
- 使用“结论—问题模型—所用工具—分析—行动—更新条件”的纵向结构。
- 工具名称只作为导航；正文以机制、证据和决策影响为主。
- 仅在比较方案、情景或概率范围时使用表格；单元格不得塞入长段落。
- 外部事实需要就近来源；用户事实、推断、价值判断和未知应可区分。
- 高风险建议要显式呈现能力边界、专业复核和不可逆后果。
- 简单问题允许缩短结构；不得为了格式完整而制造无用章节。

视觉上采用克制的 Markdown 层级，不使用装饰性卡片、重复摘要或概念墙。
