# 主要失败模式

- 交互只有装饰变化，无法解释教学因果关系。
- HTML 看似完整，但配置 JSON、内联脚本或状态机实际无效。
- 重置只恢复部分变量，导致初始状态不可复现。
- 教学动作引用不存在、重复或不可见的 DOM 目标。
- 把理想化公式、主观视觉效果或未经核对的范围声称为绝对正确。
- 页面只能依附某个宿主运行，缺少独立运行能力或清晰适配边界。
- 把术语目录直接变成页数，导致同一因果模型被过度拆分，例如为同一变量的每个档位单独做一页。
- 为了显得完整，把标题、目标、场景、控制台、预设、指标、轨迹和解释同时铺在默认首屏。
- 只解释概念定义，没有具体情境、输入或条件、关键机制和可观察结果，学习者不知道这个知识解决什么问题。
- 把命令或代码作为孤立附录，未与当前变量和可视结果同步，学习者仍不知道怎样迁移到真实环境。
- 综合实验与概念页重复，或者把综合实验的全部复杂度提前塞进每个概念页。
