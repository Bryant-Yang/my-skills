# 从认知过程设计理解

用于生成或改进教学内容、交互和讲解。这里的规则是教学设计决策，不是对所有人的固定心理定律；不要按“视觉型/听觉型学习者”贴标签，也不把工作记忆容量写成固定页面条数。

## 先定义理解的证据

规格先回答三个问题：学生已有的具体经验是什么；最可能混淆哪两个概念；离开当前例子后应当能解释或预测什么。缺少学习者信息时采用与主题相符的合理起点，并说明假设，不先发一轮通用问卷。学段同时决定密度与抽象度：低学段单页元素更少、对象更具体；同一主题跨学段交付时按学段调整默认密度并说明假设。

把“理解了 X”改为可观察的任务，例如“堵住出口后，能预测哪一处压力先变化，并用流路解释”，而不是“能点开压力说明”。设计者走通任务只证明任务可用；只有实际学习者测试才能提供学习效果证据。

## 学习路径及其界面后果

| 设计依据 | 在课件中的执行方式 | 要避免的失败 |
|---|---|---|
| 用已有知识搭建新模型 | 从具体任务、对象和初始状态开始；首次出现术语时贴着对应对象解释 | 第一屏给缩写墙，要求学生自行补背景 |
| 限制同时处理的信息，逐步建立组块 | 一次突出一条因果变化；保留必要的前后状态；新手先看完整示范，再补一步，最后独立操作 | 只删文字却把核心机制藏起来，或强迫新手盲试 |
| 联结图示与语言，减少来回寻找 | 短标签贴近对应部件/箭头；讲解指向当下变化；颜色和对象身份跨状态一致 | 图在一端、解释在另一端；字幕逐字重复整段旁白并遮图 |
| 把短暂动态变成可检查的状态 | 按机制分段，支持暂停、步进、回看或前后对照；强调变了什么及为什么 | 自动动画一闪而过，只允许从头重播 |
| 对比帮助区分条件和机制 | 先走正常流程，再只改一个关键条件；并列或可恢复地比较结果 | 多个变量同时变，学生无法归因 |
| 具体与抽象需要显式连接 | 展示“这个对象/动作”与“术语/符号/公式项”的对应，再换一个表面不同的实例 | 举完例子直接扔公式，或让类比暗示错误机制 |
| 提取与解释用于检查理解 | 示范后让学生先预测或解释，再揭示结果；提供指出具体误解的反馈 | 答案就在问题旁边；只提示“错了，再试试” |
| 迁移和间隔复习有助于保持与应用 | 多页课件在后页用短任务重新调用前页机制；单页提供换条件的应用题 | 重复同一道选项题，把记按钮位置当作理解 |

这些做法要服务于目标，不要求每页增加八块 UI。学习路径可以在同一个主视图逐步呈现；“结论区”在练习时可先显示预测提示，作答或选择查看解析后再显示答案，不强迫作答才能继续阅读。

## 把“说清楚”落实成因果链

涉及系统、协议或流程时，用具体角色和定向箭头交代：

1. 谁持有什么状态，谁要完成什么任务；同一实体在不同链路中的角色可能不同。
2. 谁向谁发出什么输入或动作；箭头说明方向和承载物，不能只画连接线。
3. 接收动作后，哪个状态因什么规则改变；什么条件满足后才允许下一步。
4. 谁观察到结果，凭什么判定完成；确认接收、完成处理和业务成功应区分。
5. 关键失败出现在哪里；谁检测、谁重试或补偿、谁保留状态。只覆盖支撑目标的异常，不展开所有规范条款。

涉及物理或结构时，替换为对象、作用条件、约束、状态变化和观测量。明确时间方向与单位；慢放、剖切、位移夸张等教学处理要标明，不能造成错误物理推断。

先展示一条无异常的完整过程，再添加会暴露核心机制的反例。具体解释之后引入术语，最后映射到真实命令、配置、公式或操作。必要机制属于主线；完整日志和罕见边界才是可折叠细节。

## 理解检查与纠错

每页选择一个紧贴核心目标的检查即可，不建设题库系统：

- **预测**：先给条件，让学生选择/设置预期结果，再运行实验与预测比较。
- **解释**：要求连接原因与结果；若没有可靠的自动判定方法，显示参考推理并让学生自查，不假装关键词匹配理解了自由回答。
- **迁移**：换对象、数值或情境，保留同一机制；结论应由规则推出，不能照抄原例。

错误反馈指出冲突发生在哪一段机制，并允许回到该状态重看。选择题的干扰项来自真实误解；计算与状态判断用确定性代码。避免要求运行时 LLM、登录、收集个人学习数据才能完成课件。

“看不懂”的修复顺序：定位跳过的角色/机制或术语 → 用具体状态补上缺口 → 用单条件对比显露差异 → 用预测检查验证解释是否可用。不要仅增加篇幅、动画、3D 或卡片。

## 依据与适用边界

设计参考 IES/WWC 的 [Organizing Instruction and Study to Improve Student Learning](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)：交替示范与练习、结合图示和语言、连接具体与抽象、提取练习及解释性问题。各建议证据强度与适用条件不同；本页把这些方向转换为课件设计约束，不声称特定页面已提高学习成绩。制作时如需要精确引用或研究结论，应读取原文核对，不能用本参考代替研究证据。
