# PWM 呼吸灯示例

本例只演示如何把知识点转成通用生成规格，不规定最终视觉风格或宿主系统。

## 输入

```text
主题：PWM 呼吸灯调光
学习者：电子技术初学者
目标：理解占空比、频率与负载响应的关系
```

## 单页教学合同

> 让学生通过调节占空比、频率和负载类型，观察 PWM 方波、平均输出与负载状态的变化，比较低/高占空比和低/高频率，从而理解 PWM 参数如何影响 LED、舵机和电机。

## 变量—现象映射

| 知识点 | 变量/控件 | 可观察现象 | 对比状态 | 因果结论 |
|---|---|---|---|---|
| 占空比决定平均输出 | `duty_cycle` slider | 高电平宽度、平均值、LED 亮度 | 20% / 50% / 80% | 占空比增大通常提高平均输出 |
| 频率决定周期 | `frequency` slider | 周期长度、低频闪烁感 | 10Hz / 500Hz | 频率增大使周期缩短并减弱可见闪烁 |
| 负载响应不同 | `load_type` selector | LED 亮度、舵机角度、电机速度 | LED / servo / motor | 同一 PWM 参数在不同执行器中代表不同控制意义 |

## 页面结构建议

```text
标题 + 学习目标
├── 控制区
│   ├── 占空比
│   ├── 频率
│   ├── 负载类型
│   └── 启动 / 暂停 / 重置 / presets
├── PWM 波形区
├── 负载响应区
└── 实时数据与一句因果解释
```

## 典型状态

- 20% duty：短高电平、较低平均输出、LED 较暗。
- 80% duty：长高电平、较高平均输出、LED 较亮。
- 低频：允许学生明显观察开/关切换。
- 高频：强调人眼感受到的是平均亮度。

## 学科边界

- LED 视觉亮度与占空比并非在所有硬件上严格线性；教学页应说“通常提高平均亮度”，不要伪造精确感知曲线。
- 舵机控制依赖脉冲宽度和周期，不应简单把占空比直接等同于角度，除非明确采用的信号模型。
- 电机速度受驱动器、负载、电源和机械惯性影响；简单模拟需要标注理想化假设。

这个边界说明比漂亮动画更重要：生成模型可以设计视觉，但不能把方便展示的近似当成普遍物理定律。
