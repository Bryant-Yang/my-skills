# 课件质量门禁

验证分为三层，与任何宿主产品无关。只有真实执行过的检查才能写成“已通过”。

## A. 确定性结构检查

运行：

```bash
node scripts/validate-courseware.js <courseware.html> --json
```

默认拒绝绝对或相对的外部资源与静态可识别网络请求。只有用户明确批准时才追加 `--allow-external-dependencies`，并在验证报告中逐项列出。

错误必须清零：

- 文件可读取且非空；
- 恰好一个 DOCTYPE、`html` 开始/结束标签和 `body`；
- 存在 viewport；
- 存在 Canvas 或 SVG；
- 存在交互控件；
- 恰好存在一份 `courseware-config`，JSON 可解析且根值为对象；
- `schemaVersion=1`、`kind=simulation`、topic 合法，变量数组非空且变量名唯一；
- 数值变量和枚举变量的必需字段、默认值、范围、options 与 presets 值均合法；
- 需要宿主桥接时，存在 `message` 监听和四种 `COURSEWARE_*` 处理器标记；
- 不存在未获批准的外部脚本、样式、媒体、iframe 或静态可识别网络请求。

警告需要人工判断：

- 变量缺少稳定 DOM hook；
- 缺少 presets、ARIA、键盘支持或 `requestAnimationFrame`；
- 存在可能的固定 Canvas 尺寸；
- 内联脚本无法通过保守语法探测。

此脚本不执行 HTML，因此处理器标记通过不代表消息语义正确；布局、状态同步、选择器可见性和学科模型仍需浏览器或人工检查。

## B. 浏览器行为检查

能控制浏览器时至少检查：

1. 在 1440×900、768×1024、390×844 视口加载。
2. 页面无横向滚动，控制区不遮挡可视化。
3. 控制台无 `error` 和 `unhandledrejection`。
4. 每个变量分别取最小、中间、最大或各枚举值。
5. 控件值、实时显示和可视化同步改变。
6. 所有 presets 生效并形成不同状态。
7. 启动、暂停、继续、重置行为与文字一致。
8. 重置后状态与首次加载一致。
9. 如启用宿主桥接，对四种 `COURSEWARE_*` 消息各做一次 smoke test。
10. 教学动作中的每个选择器存在、唯一且可见。
11. 初始视口能识别本页问题、主要操作和核心现象；桌面端主按钮无需滚动即可看到。
12. 默认折叠的命令、完整规则或协议轨迹可以展开、读取并再次收起，且展开前核心结论不缺失。

如果无法运行浏览器，将这些项目写为“未检查”，不能省略。

## C. 教学与学科检查

人工或来源核对：

- 单页目标是否清楚且没有塞入多个主题；
- 标题是否是学习者要回答的问题，而不是只展示术语；
- 真实案例是否具体说明“谁、输入什么、经过什么、谁收到、如何判断结果”；
- 涉及工具或协议时，是否给出与当前状态一致的最小真实用法；
- 交互是否形成“变量—现象—比较—结论”；
- 公式、单位、范围、默认值和边界情况是否正确；
- 动画是否代表真实关系，而不是只追求视觉效果；
- presets 是否覆盖关键对比而非随意数值；
- 教师动作是否先提示观察，再改变状态，最后解释因果；
- 语言和术语是否适合目标学习者。

### 认知负担检查

- 默认界面是否只有一个主要操作和一个视觉焦点；
- 控制区是否只暴露直接影响本页结论的变量，通常不超过 3 个；
- 指标是否能解释因果，而不是为了显得完整而堆叠；
- 是否存在连续同等级的目标卡、场景卡、提示卡、指标卡和解释卡；如有，能否合并为一句说明、一个结果条或次级展开区；
- 命令、推导、协议轨迹和边界条件是否按需展开，同时保留可发现性；
- 概念页是否因综合实验需求而提前承担完整控制台复杂度。

## D. 紧凑课件组检查

仅在交付多页课件时执行：

1. `index.html`、所有概念页、验证报告和 `README.md` 位于同一目录。
2. 页数可以由学习问题、因果模型、观察对象和先备关系解释；同一模型的并列档位没有被拆成多页。
3. 目录页是一条可读学习路径，包含一个明确开始入口，不使用大量同等级宣传卡片干扰顺序。
4. 每页都有上一页、下一页或目录导航；所有本地链接实际可达。普通 `<a>` 页间导航不按外部资源处理。
5. 贯穿案例、术语、消息或数据在页面之间一致。
6. “解决什么问题”和“怎样使用”已进入主线，而不是只出现在附录或最后一页。
7. 综合实验如存在，应明确为可选末页，并要求整合应用而不是重复概念页。

`index.html` 只承担学习路径与导航，不要求满足模拟器 validator 的 `courseware-config`、变量、控件和 Canvas/SVG 合同；应单独检查 HTML 结构、开始入口、页面顺序和链接可达性。概念页与综合实验页仍逐页运行确定性校验器。

高风险学科内容在没有来源或专家复核时必须标为“学科正确性待复核”。

## 完成判定

- 结构错误大于 0：未完成。
- 关键变量没有可见结果：未完成。
- 教学动作引用不存在的选择器：未完成。
- 默认首屏无法识别主要问题或主操作被次级信息淹没：未完成。
- 多页课件按术语过度拆分、链接不可达或缺少真实用法：未完成。
- 浏览器或学科检查未执行：可以交付候选稿，但必须明确写“未检查”，不能称为全部验证通过。
