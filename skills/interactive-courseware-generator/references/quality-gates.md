# 课件质量门禁

验证分为三层，与任何宿主产品无关。只有真实执行过的检查才能写成“已通过”。

## A. 确定性结构检查

运行：

```bash
node scripts/validate-courseware.js <courseware.html> --json
```

默认拒绝绝对或相对的外部资源与静态可识别网络请求。只有用户明确批准时才追加 `--allow-external-dependencies`，并在验证报告中逐项列出。

错误必须清零：

- 文件可读取且非空；
- 恰好一个 DOCTYPE、`html` 开始/结束标签和 `body`；
- 存在 viewport；
- 存在 Canvas 或 SVG；
- 存在交互控件；
- 恰好存在一份 `courseware-config`，JSON 可解析且根值为对象；
- `schemaVersion=1`、`kind=simulation`、topic 合法，变量数组非空且变量名唯一；
- 数值变量和枚举变量的必需字段、默认值、范围、options 与 presets 值均合法；
- 需要宿主桥接时，存在 `message` 监听和四种 `COURSEWARE_*` 处理器标记；
- 不存在未获批准的外部脚本、样式、媒体、iframe 或静态可识别网络请求。

警告需要人工判断：

- 变量缺少稳定 DOM hook；
- 缺少 presets、ARIA、键盘支持或 `requestAnimationFrame`；
- 存在可能的固定 Canvas 尺寸；
- 内联脚本无法通过保守语法探测。

此脚本不执行 HTML，因此处理器标记通过不代表消息语义正确；布局、状态同步、选择器可见性和学科模型仍需浏览器或人工检查。

## B. 浏览器行为检查

能控制浏览器时至少检查：

1. 在 1440×900、768×1024、390×844 视口加载。
2. 页面无横向滚动，控制区不遮挡可视化。
3. 控制台无 `error` 和 `unhandledrejection`。
4. 每个变量分别取最小、中间、最大或各枚举值。
5. 控件值、实时显示和可视化同步改变。
6. 所有 presets 生效并形成不同状态。
7. 启动、暂停、继续、重置行为与文字一致。
8. 重置后状态与首次加载一致。
9. 如启用宿主桥接，对四种 `COURSEWARE_*` 消息各做一次 smoke test。
10. 教学动作中的每个选择器存在、唯一且可见。

如果无法运行浏览器，将这些项目写为“未检查”，不能省略。

## C. 教学与学科检查

人工或来源核对：

- 单页目标是否清楚且没有塞入多个主题；
- 交互是否形成“变量—现象—比较—结论”；
- 公式、单位、范围、默认值和边界情况是否正确；
- 动画是否代表真实关系，而不是只追求视觉效果；
- presets 是否覆盖关键对比而非随意数值；
- 教师动作是否先提示观察，再改变状态，最后解释因果；
- 语言和术语是否适合目标学习者。

高风险学科内容在没有来源或专家复核时必须标为“学科正确性待复核”。

## 完成判定

- 结构错误大于 0：未完成。
- 关键变量没有可见结果：未完成。
- 教学动作引用不存在的选择器：未完成。
- 浏览器或学科检查未执行：可以交付候选稿，但必须明确写“未检查”，不能称为全部验证通过。
