# 精确 3D：Blender bpy 建模与课件交付

## 选择表达方式

- 二维足以说明的流程、函数、报文或平面几何，使用 SVG/Canvas；不为增加视觉复杂度而引入 3D。
- 学习目标依赖空间结构、遮挡、剖面、装配、轴线或三维运动时，判断需要哪些真实几何关系。需要精确 3D 建模时，必须用 Blender 的 Python API `bpy` 生成模型，不能以图像生成或凭目测拼接替代。
- “精确”指相对于规格可验证：尺寸、比例、单位、拓扑/连接、运动约束及允许误差。教学模型不自动具有制造、诊断或工程认证精度。没有真实尺寸时，可用明确标注的理想化参数模型解释原理，不能宣称是某真实产品的精确复刻。
- 装配和内部结构可用剖切/爆炸视图，但要保留整体定位和复位入口。改变观察角度有教学价值时提供旋转与标准视图；任意旋转不能代替标注和机制解释。

## 建模规格先于脚本

记录到 `model/spec.json` 或等价可读文档：

- 来源及适用对象，关键参数、单位、坐标轴与原点、尺寸公差；区分真实测量、资料值和教学假设。
- 部件语义名称、父子关系、接触/间隙、旋转轴和枢轴、运动范围；哪些几何关系影响教学结论。
- 控件改变哪些模型参数，哪个可见量是结果；相机变化不计为学科变量反馈。
- 可简化的细节，以及不得破坏的流道、齿形、截面、角度、连接或比例。
- 展示方式：可旋转网格，还是固定视角的渲染/状态图；选择必须支持目标交互。

缺失尺寸但不影响原理时使用有依据的参数假设；缺失会改变关键结论时只澄清该项，继续可独立完成的课件部分。

## 制作与检查顺序

1. 检查当前环境的 Blender 可执行文件及版本。`bpy` 运行在 Blender 自带 Python 中；不要默认系统 Python 的 `import bpy` 可用。不擅自下载大型运行时或改变全局配置。
2. 编写 `model/build_scene.py`，读取显式参数，在新的后台进程中建立独立场景。设置场景单位；优先使用数据 API，使用 `bpy.ops` 时明确模式、活动对象和选择集，避免依赖当前 UI。不要改用户已打开的工程。
3. 保留稳定语义对象名、可理解的层级及正确枢轴。变换、修改器与实例需要在验证中正确求值；不能把未求值的网格尺寸当作最终结果。
4. 用脚本断言关键尺寸与几何/运动关系，记录目标值、实测值、单位和公差。例如轴距、孔径、齿数、比例、关节范围；按题材检查流道连通、部件干涉等，不把包围盒通过当作全部精度证明。
5. 保存 `.blend`，导出实际用于课件的 GLB、数据或渲染图。导出后重新载入/检查，核对轴向、单位、比例、对象名、材质及动画。注意 Blender 与 glTF 的坐标约定转换，以对应坐标或不变量比较，不能逐轴盲比。
6. 从标准视图以及揭示内部关系的视图检查遮挡、标注、接触和方向；检查教学运动的关键状态及连续约束，不能只验一帧。
7. 在实际页面中核对导出物和学科状态一致：输入值、部件运动、注释、观测量同步；暂停、步进、复位和预设正确。相机复位与实验复位应清楚区分。

命令形态（把占位参数替换为实际路径）：

```bash
blender --background --factory-startup --python-exit-code 1 --python model/build_scene.py -- --output-dir model
```

`--` 后参数由自己的脚本解析。`--python-exit-code 1` 使 Python 异常反映为失败退出码；仍需验证文件存在和几何断言结果，不能只凭进程启动或日志里有“saved”判成功。命令按当前版本官方文档核对。

## 页面嵌入与源文件

制作时使用 Blender，不意味着学习者安装 Blender。默认交互页仍是自包含 HTML：

- 需要实时三维交互时，将导出的几何/GLB 数据及必要渲染代码内嵌，保留依赖许可说明；使用内存解析、TypedArray 或内嵌资源，不依赖网络加载器。WebGL 使用 Canvas，继续满足页面结构合同。
- 固定视角已经足够时，可内嵌由该模型渲染的图像/离散状态帧，并在 Canvas/SVG 上叠加标签或操作。离散帧仅表示已渲染状态，不能伪装成任意连续参数的精确物理结果。
- 若单文件体积或设备性能不适合，可依据用户已有授权采用本地多资源包；没有此授权时先完成内嵌方案或准备好具体资源方案再说明取舍。相对 `.glb`、纹理、脚本仍是运行依赖，需按现有规则申明，不能偷偷开启放行参数。
- WebGL 不可用时给出清楚的静态标准视图/文字替代，披露哪些空间交互不可用；不能将降级页面称为全部功能通过。

直接构建交付 `build_scene.py`、参数规格、`.blend`、实际使用的导出资源，以及几何检查结果（可并入课件验证报告）。这些源附件不改变 HTML 默认可独立运行的要求。只生成提示词时，输出上述制作合同与验收要求，不宣称已制作资产。

## 验收与停止条件

报告至少列出：Blender 版本/执行命令、输入参数和来源、关键尺寸/关系的目标值与实测误差、公差、导出复核、标准视图证据、实际页面的关键状态与移动端表现、依赖与简化说明。

工具缺失或执行失败时，明确“精确 3D 建模未完成”，继续独立的规格和教学设计；不得静默用假 3D 替代。几何关系错误、缺少精度依据或未做导出后检查时，不能宣称精确模型已验收。脚本正确不等于物理模型正确，几何检查也不等于教学有效。
