# 学科可视化语言

主题属于学校学科或成熟工程领域时，图示必须使用该学科的母语——本学科用来思考和表达的图形语言。学科图示是学习内容本身，不能降级为装饰；选错母语，交互再流畅也建不起正确的学科模型。

## 按学科选母语

| 学科/领域 | 母语可视化 | 教学要点与典型失败 |
|---|---|---|
| 数学 | 几何图、数轴、函数图像、分步推导式 | 图形即认知目标；只给公式不给图等于只给结论不给直观 |
| 物理 | 受力图、电路图、过程图像（x-t、p-V）、情境到模型的抽象箭头 | 每个箭头和符号有物理含义，不违反学科绘图约定 |
| 化学 | 宏观现象 ⇄ 微观粒子 ⇄ 符号方程三重表征 | 三层同屏互证并用一致色标关联；只给现象不给微观解释只讲了一半 |
| 生物 | 结构—功能对应图（模式图、剖视、显微）、过程流程 | 结构与功能成对出现；比例和位置失真会形成错误模型 |
| 地理 | 地图、剖面图、空间尺度递进（局部→区域→全球） | 空间关系是内容本身；示意图注明非真实比例 |
| 历史 | 时间轴、历史地图、史料与器物图 | 时间轴作骨架而非装饰条；区分史实与推断 |
| 语文 / 英语 | 文本结构图、情境图、表达支架 | 图示服务于理解与表达，不替代文本细读 |
| 道德与法治 | 真实生活情境案例、两难选择对比 | 情境要承载真实价值冲突，不做说教口号图 |
| 信息科技 / 协议 | 状态机图、消息时序、流程图、真实命令与配置 | 按认知设计中的因果链合同执行；命令与交互状态同步 |
| 工程 / 电子 | 原理图、框图、波形与时序图 | 波形按真实时间关系绘制，参见 PWM 示例的结构 |

不属于以上领域时不强行套用，回到“变量—现象映射”选择足以表达机制的形式。

## 母语挂接到交互合同

- 学科母语图必须能挂进“知识点 → 可调变量 → 控件 → 可观察现象 → 对比状态 → 因果结论”映射；挂不进的精美图示按花边细节剔除。
- 多重表征（如化学三联）在交互中联动：改一个变量，各层表征同时更新并对齐，而不是各放各的静态图。
- 是否需要 2D 或精确 3D 仍按 Blender 参考的路由问题判断：几何、装配、遮挡或空间运动是否承载本页学习问题。

## 学科依据与来源

- 公式、常数、范围和术语优先来自用户资料或可靠来源；影响结论的不确定项必须核对。
- 引用课程标准、考纲、规范或标准文档时注明文件与位置；不凭记忆引用原文，不臆造条目编号。需要原文时用权威来源核对，找不到就不引用。
- 同一学科在不同学段的母语侧重不同（如小学科学重观察记录，初中物理重模型抽象）；按目标学习者调整，不混用超出学段的符号系统。
- 高风险学科内容没有来源或专家复核时，按质量门禁标为“学科正确性待复核”。
