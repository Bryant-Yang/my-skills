# 设计依据

本 Skill 从一页交互式教学内容的通用问题出发，不依赖任何具体产品、代码库、模型供应商或宿主协议。

## 稳定原则

1. **从学习结果倒推交互**：先确定学生应理解的因果关系，再选择变量、控件和可观察现象。
2. **先规格后实现**：教学规格负责正确方向，HTML 生成负责具体表达，避免让视觉设计替代教学设计。
3. **页面可独立运行**：默认单文件且无远程依赖，换宿主或直接打开都不影响核心课件。
4. **宿主适配可选**：通用消息桥接只承担外部控制，不参与学科计算或页面状态真相。
5. **确定性逻辑用代码**：公式、状态机、重置、范围约束和消息路由必须由普通代码实现。
6. **验证分层**：静态结构、浏览器行为、教学与学科正确性分别验证，模型自检不能替代真实执行。

## 不采用的做法

- 不绑定特定数据库、页面框架、iframe 实现或课堂数据模型。
- 不要求一个特定 LLM、API 或提示词模板加载器。
- 不复制某个产品的私有字段、动作名、存储格式或生命周期。
- 不把“能在浏览器显示”当作“教学与学科正确”。
