# My Skills

个人可复用 skill 作品集仓库。

这个仓库只放通用 skill、模板和示例，不放真实照片、真实姓名、真实日期或私有音频。

## 目录结构

- `skills/`
  每个 skill 自包含目录，包含 `SKILL.md`、脚本、参考资料和模板资源。
- `examples/`
  每个 skill 的匿名示例输入或示例 brief。
- `docs/`
  仓库级说明或后续迭代记录。

## 当前技能

- `generate-wedding-slideshow`
  根据照片目录、简短标题信息和自然语言歌单描述，快速生成一套婚礼大屏正片与分享版项目。

## 使用方式

1. 把仓库中的目标 skill 目录直接引用给 Codex，或复制到你的本地 skills 目录。
2. 按 skill 的输入要求提供照片目录、输出目录和歌单描述。
3. 由 skill 内置脚本与模板生成独立项目目录。

## 设计原则

- 每个 skill 尽量自包含，避免跨目录隐式依赖。
- 模板保持匿名、可复用、轻量。
- 优先提供可工作的最小脚本，而不是重系统。
